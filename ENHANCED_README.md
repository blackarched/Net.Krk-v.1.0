## 🔧 Installation & Setup

### 📦 **System Requirements**
- **Operating System** - Linux (Ubuntu 18.04+, CentOS 7+, Debian 9+)
- **Python** - Version 3.7 or higher
- **Memory** - 2GB RAM minimum, 4GB recommended
- **Storage** - 1GB free space
- **Network** - Ethernet or WiFi interface

### 🚀 **Quick Installation**
```bash
# Clone the repository
git clone <repository-url>
cd enhanced-network-scanner

# Run the enhanced setup script
sudo ./enhanced_setup.sh

# Launch the scanner
sudo python3 enhanced_network_scanner.py
```

### 🔧 **Manual Installation**
```bash
# Install system dependencies
sudo apt-get update
sudo apt-get install python3-dev libpcap-dev tcpdump net-tools

# Install Python dependencies
pip3 install -r enhanced_requirements.txt

# Make scripts executable
chmod +x *.py

# Run the scanner
sudo python3 enhanced_network_scanner.py
```
